# Archive

This folder preserves superseded or absorbed docs for traceability.

## What belongs here
- old mixed docs that were split into governed docs,
- docs fully absorbed into an SSoT,
- historical versions that are no longer authoritative.

## What does not belong here
- active reference docs,
- current subsystem truth,
- current roadmap or current-state docs.

## Conflict rule
Archived docs never override current docs. Every archived doc should say what replaced it.
