# Reference

This folder contains reusable supporting material.

## What belongs here
- implementation guides,
- onboarding notes,
- manual test scripts,
- reusable integration patterns.

## What does not belong here
- primary subsystem truth,
- current milestone state,
- cross-cutting contracts,
- archived superseded documents.

## Conflict rule
Reference docs lose to SSoTs, contracts, and current-state docs when they disagree.
