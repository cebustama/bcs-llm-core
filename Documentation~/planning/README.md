# Planning

This folder contains active planning documents for the package.

## What belongs here
- milestone sequence,
- next-step ordering,
- acceptance criteria,
- non-goals and cleanup tasks.

## What does not belong here
- implemented subsystem truth,
- cross-cutting contracts,
- reference/tutorial material,
- archived mixed-state docs.

## Conflict rule
If a roadmap statement conflicts with an SSoT, the SSoT wins and the roadmap must be corrected.

## Lightweight-variant note
This package currently uses a single active roadmap file and does not yet split planning into `active/` and `archive/` subfolders.
